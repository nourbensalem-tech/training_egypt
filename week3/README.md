# SQL vs NoSQL

## What is SQL?

SQL databases store data in tables made of rows and columns. Before storing data, you must define the structure of the tables. SQL databases are a good choice when the data has a fixed structure and relationships between tables.

Examples:
- MySQL
- PostgreSQL
- Microsoft SQL Server
- Oracle Database

## What is NoSQL?

NoSQL databases store data in a more flexible way. Instead of tables, they often use documents. Each document can have a different structure, making it easier to work with changing data.

Examples:
- MongoDB
- Firebase Firestore
- Cassandra
- Redis


## SQL vs NoSQL

| SQL | NoSQL |
|------|--------|
| Stores data in tables | Stores data in documents |
| Fixed schema | Flexible schema |
| Uses SQL language | Does not require SQL |
| Best for structured data | Best for flexible data |
| Supports joins | Usually avoids joins |
| Vertical scaling | Horizontal scaling |
